<objective>
Carve interior maze tiles into each room's Uint8Array grid. Plan 01 created room objects
with `grid: null`. This plan allocates each grid, runs recursive backtracking + corridor
widening + ~12% loop removal for Normal/Elite/Shop rooms, and uses open-floor layout for
Start/Boss rooms. After carving, it places door tiles on room borders per each room's
connections array, runs tile-level BFS to validate interior reachability (retry on failure),
and computes player spawn and enemy spawn lists for every room.

Purpose: After this plan, every room in currentLevel.rooms has a populated, validated
Uint8Array grid ready for Phase 03 to render and Phase 41 to add player movement.

Output:
- carveRoom(room, rng) — recursive backtracking maze carver for Normal/Elite/Shop rooms
- buildOpenRoom(room) — open-floor builder for Start/Boss/Shop rooms
- placeDoors(room, allRooms, connections) — inserts door tiles on borders
- tileBFS(grid, rows, cols, startRow, startCol) — BFS over tile grid; returns reachable set
- computeSpawnPoints(room) — assigns room.spawnPoint and room.spawnList
- All room.grid fields populated (Uint8Array) before renderRoom() is called
</objective>

  <behavior>
    - buildOpenRoom(room): allocates Uint8Array(rows*cols), fills all tiles with 0 (floor),
      then sets all border tiles (row=0, row=rows-1, col=0, col=cols-1) to 1 (wall).
      Result: open interior, solid border.
    - carveRoom(room, rng): allocates Uint8Array(rows*cols) filled with 1 (all walls).
      Uses recursive backtracking on a cell grid of (rows-1)/2 × (cols-1)/2 cells at
      odd-indexed positions (1,1), (1,3), (3,1)…. Carving sets cells and knocked-out walls
      to 0 (floor). After carving, corridor widening: for each carved corridor (the even-row
      or even-col tile between two cells), mark the adjacent even-row/col tile as floor too
      (2-wide corridors per D-08). After widening, loop removal: iterate all wall tiles that
      have at least 2 floor neighbors (N+S or E+W); for ~12% of them, set to floor (per D-09,
      seeded with rng).
    - Tile values: 0=floor, 1=wall, 2=door-N, 3=door-E, 4=door-S, 5=door-W (D-01).
    - Same seed → same carved room (D-13).
  </behavior>
  <action>
    Add two functions to game.js after generateLevel(). Insert them in a new
    `// Room interior generation` comment section.

    == buildOpenRoom(room) ==
    Allocates `room.grid = new Uint8Array(room.rows * room.cols)` filled with 0.
    Sets border tiles to 1:
      - Row 0 and row (rows-1): all cols set to 1.
      - Col 0 and col (cols-1): all rows set to 1.
    Does NOT place door tiles — placeDoors() does that in Task 2.

    == carveRoom(room, rng) ==
    1. Allocate: `room.grid = new Uint8Array(room.rows * room.cols).fill(1);`
       (All walls initially.)
    2. Cell grid dimensions: `cellRows = (room.rows - 1) / 2`, `cellCols = (room.cols - 1) / 2`.
       Cell at (cr, cc) maps to tile (cr*2+1, cc*2+1). These are the "chamber" tiles.
    3. Visited array: `new Uint8Array(cellRows * cellCols)` filled with 0.
    4. Iterative DFS (stack-based — avoids call stack overflow for large rooms):
       - Start at cell (0, 0). Mark visited. Push to stack.
       - While stack non-empty:
         * Current = stack top (peek, do not pop yet).
         * Shuffle neighbors: [N, E, S, W] directions; filter to unvisited in-bounds cells.
         * If neighbors exist: pick one via `Math.floor(rng() * neighbors.length)`.
           - Set the wall tile between current and chosen cell to 0 (floor).
           - Set the chosen cell tile itself to 0 (floor).
           - Mark chosen cell visited. Push to stack.
         * If no unvisited neighbors: pop stack (backtrack).
       - Also set the starting cell (1, 1) tile to 0 after the loop.
    5. Corridor widening (D-08):
       After DFS completes, iterate all "passage" tiles (tiles with even row or even col,
       excluding row 0, rows-1, col 0, cols-1). For each passage tile that is 0 (floor),
       check if it connects two cells along a row (even row, both neighbors on the same
       row are floor) or along a column (even col, both neighbors same col are floor).
       In that case, mark the tile at row+1 or col+1 (whichever is the even-indexed
       direction) also as floor — widening the corridor to 2 tiles.
       Constraint: do not widen into border tiles (row 0, rows-1, col 0, cols-1).
    6. Loop removal (D-09):
       After widening, collect all wall tiles (value 1) that have at least one floor neighbor
       to the N and at least one floor neighbor to the S, OR at least one floor neighbor to
       the E and at least one to the W (bridge walls). For ~12% of these, set to 0 (floor).
       Selection: iterate list, set floor if `rng() < 0.12`.

    Both functions must be inserted such that generateLevel() calls them for each room:
    After creating all room objects in generateLevel(), iterate rooms and call:
      - buildOpenRoom(room) for types "START", "BOSS", "SHOP"
      - carveRoom(room, rng) for types "NORMAL", "ELITE"

    Decision coverage: D-01, D-07, D-08, D-09, D-10, MAZE-02.

    == tileBFS(grid, rows, cols, startRow, startCol) ==
    Standard BFS over the grid:
      - Queue starts with [startRow, startCol].
      - A tile is traversable if its value is 0 (floor) or 2–5 (door).
      - Returns a Set of "row,col" strings for all reachable tiles.
      - Returns empty Set if startRow/startCol tile is a wall (value 1).
    This function is used for:
      (a) Tile-level reachability validation (D-15): after carving, run BFS from the
          center tile; if any door tile is unreachable, regenerate the room (single retry
          by calling carveRoom again with a perturbed seed offset).
      (b) Spawn validation (D-22).

    == computeSpawnPoints(room) ==
    For the player spawn (D-20):
      - Run tileBFS from the room center tile to get all reachable floor tiles.
      - Filter to tiles where all 8 neighbors within a 3-tile Manhattan radius are also
        floor (i.e., at least 3 tiles from any wall or door) — simplified: check that the
        tile at (ty-3, tx), (ty+3, tx), (ty, tx-3), (ty, tx+3) are all floor tiles.
      - If no such tile exists, relax to 2-tile distance.
      - Pick the first qualifying tile (lowest row, then lowest col — deterministic).
      - Assign room.spawnPoint = { tx, ty }.
    For the enemy spawn list (D-21):
      - From the same BFS reachable set, filter to tiles where:
        (a) Manhattan distance from spawnPoint >= 4 tiles, AND
        (b) At least 2 tiles from any door tile (check all 4 door midpoints).
      - Store result as room.spawnList = [{ tx, ty }, ...].

    == generateLevel() integration ==
    After carving all rooms (Task 1) and placing doors, run per-room validation:
      For each room:
        1. Find any door tile in room.grid (first tile with value 2–5).
        2. Run tileBFS from the center tile (Math.floor(rows/2), Math.floor(cols/2)).
        3. If the door tile position is NOT in the BFS reachable set: regenerate the room
           once (call carveRoom with seed + 1000 + room.id for determinism) and re-run BFS.
        4. If still not reachable after one retry: leave the room as-is and log a console
           warn: "[Phase40] Room", room.id, "door unreachable after retry — using as-is".
      After validation, call computeSpawnPoints(room) for every room.

    Decision coverage: D-11, D-14, D-15, D-20, D-21, D-22, MAZE-04.
