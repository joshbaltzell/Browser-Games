Implement the right-hand rule using facing direction index: 0=N 1=E 2=S 3=W.
Direction vectors array (inline):
  N: (0,-1), E: (1,0), S: (0,1), W: (-1,0)
  Store as `var DIRS = [[0,-1],[1,0],[0,1],[-1,0]];`

Right-hand rule probe order (relative to current facing):
  - Right of current = (facing + 1) % 4
  - Forward = facing
  - Left = (facing + 3) % 4
  - Back = (facing + 2) % 4

Passability check helper (inline, no new function):
  `function tryDir(nx, ny) { var tc = Math.floor(nx/TILE_SIZE); var tr = Math.floor(ny/TILE_SIZE); return tc >= 0 && tc < cols && tr >= 0 && tr < currentRoom.rows && currentRoom.grid[tr*cols+tc] !== 1; }`
  Note: because this is inside updateEnemies scope and `var` is used, declare the helper as an inline named function expression or inline the check directly into each probe.

Movement steps:
  1. Try turn-right: newFacing = (e.facing + 1) % 4. Probe `e.x + DIRS[newFacing][0]*e.speed*dt`, `e.y + DIRS[newFacing][1]*e.speed*dt`. If passable → set `e.facing = newFacing`, move there.
  2. Else try forward: probe current facing. If passable → move.
  3. Else try turn-left: newFacing = (e.facing + 3) % 4. If passable → set facing, move.
  4. Else U-turn: `e.facing = (e.facing + 2) % 4`. Move (or stay if U-turn target is also blocked, which is degenerate).

For actual position update: after choosing the new facing, compute:
  `var nx = e.x + DIRS[e.facing][0] * e.speed * dt;`
  `var ny = e.y + DIRS[e.facing][1] * e.speed * dt;`
  `e.x = nx; e.y = ny;`

Use `var cols = currentRoom.cols;` from the outer `updateEnemies` scope (already declared at line ~1266).
