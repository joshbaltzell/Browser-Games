STEP A — updateEnemies() Sniper branch (add after the SENTINEL block, before closing `checkEnemiesClear()`):
Add `} else if (e.type === "SNIPER") {` and implement the 4-state machine:

  idle state: decrement `e.stateTimer`. When <= 0, transition to aim:
    - lock direction: compute `(player.x - e.x, player.y - e.y)`, pick nearest of 4 cardinal vectors `{0,-1},{1,0},{0,1},{-1,0}` by dot product — whichever maximizes `dx*norm.x + dy*norm.y`. Store as `e.aimDx, e.aimDy`.
    - `e.state = "aim"; e.stateTimer = 1.2;`

  aim state: decrement `e.stateTimer`. When <= 0, transition to fire: `e.state = "fire"; e.stateTimer = 0;`

  fire state (runs once, same frame as transition from aim):
    - Compute beam endpoint: march from `e.x, e.y` along `(e.aimDx, e.aimDy)` in steps of 4px until hitting a wall tile or room boundary. Store endpoint as `e.beamEndX, e.beamEndY`.
    - Hit-test player: compute perpendicular distance from player to the beam line segment from `(e.x, e.y)` to `(e.beamEndX, e.beamEndY)`. Also ensure player projects onto the segment (clamp t to [0,1]).
    - If perpendicular distance < 6 AND `player.invuln <= 0`: `player.hp -= 1; player.invuln = INVULN_DURATION; if (player.hp <= 0) gameState = GAME_STATE.DEAD;`
    - Transition: `e.state = "cooldown"; e.stateTimer = 2.5;`

  cooldown state: decrement `e.stateTimer`. When <= 0: `e.state = "idle"; e.stateTimer = 2.0;`

Perpendicular distance helper (inline, no new function needed):
  `var bex = e.beamEndX - e.x; var bey = e.beamEndY - e.y;`
  `var blen2 = bex*bex + bey*bey;`
  `var t = blen2 > 0 ? ((player.x-e.x)*bex + (player.y-e.y)*bey) / blen2 : 0;`
  `var t2 = Math.max(0, Math.min(1, t));`
  `var closestX = e.x + t2*bex; var closestY = e.y + t2*bey;`
  `var perpDist = Math.sqrt((player.x-closestX)*(player.x-closestX) + (player.y-closestY)*(player.y-closestY));`
